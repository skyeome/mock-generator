# Learnings

## AI-First Schema Inference Pattern

**Date**: 2026-02-01

### Implementation Strategy
Implemented AI-first schema inference with graceful fallback to regex-based enrichment:

1. **Try AI Analysis First**: Calls `/api/ai/analyze-schema` endpoint with POST request containing schema and config
2. **Parse AI Response**: Type assertion for response data to match expected structure with `success` and `analysis` fields
3. **Apply AI Hints**: Maps AI semantic suggestions to Faker methods with confidence scores
4. **Silent Fallback**: On any error (network, 503, parsing), falls back to `enrichSchemaWithSemantics` without disrupting user experience
5. **State Tracking**: `isUsingAI` state exported for UI feedback if needed

### Key TypeScript Patterns
- Type assertion for `fetch` response: `as { success?: boolean; analysis?: ... }` to handle unknown JSON
- Async callback in React hook requires careful handling with useCallback
- Helper functions (`applyAIAnalysis`, `mapSemanticToFaker`) placed outside hook to avoid recreation

### Semantic to Faker Mapping
Comprehensive mapping table covers common data types:
- Personal data: firstName, lastName, fullName, email, phone
- Location: city, country, streetAddress, zipCode
- Business: company, jobTitle, price
- Technical: uuid, id, url, date, datetime
- Primitives: boolean, integer, number

### Error Handling
- Try-catch around AI fetch prevents breaking existing flow
- Console.log for debugging without user-facing errors
- Finally block ensures `isUsingAI` state reset regardless of success/failure

### Type Safety
- Import `JsonSchema` type from `@/lib/types` for schema operations
- Explicit return types on helper functions
- Type-safe property access with conditional checks
